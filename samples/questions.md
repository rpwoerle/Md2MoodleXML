## AI-Text: Erläutere kurz was das Internet und was das World-Wide-Web (WWW) ist. Gehe dabei auch auf die unterschiedlichen Adressierung (URL und IP-Adresse) ein.||Internet und WWW [4]
Der Antworttext sollte folgende Begriffe und sinngemäßen Erläuterungen enthalten:
INTERNET: das Internet ist ein weltweiter Zusammenschluss von sehr vielen Computern (Rechnern) zwischen denen Daten übertragen werden können. Sie sind über eine Netzwerkstruktur mit einander verbunden. Damit Computer miteinander kommunizieren oder Daten austauschen können, benötigen sie eine weltweit bekannte IP-Adresse (eine eindeutige Zahlenkombination).
WORLD-WIDE-WEB: das WWW ist ein Dienst im Internet bei dem Dokumente über eine Hypertextstruktur mit URLs aufeinander verweisen. Eine URL (Uniform Resource Locator) ist ein speziell codierter Verweis (Link). Dazu wird meist das Hypertext-Protokoll HTTP oder seine verschlüsselte Variante HTTPS verwendet. Eine URL im WWW muss durch einen DNS (Domain-Name-Service) Service in eine IP-Adresse übersetzt werden, damit der zugehörige Computer gefunden werden kann.
